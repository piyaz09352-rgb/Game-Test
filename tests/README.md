# ชุดทดสอบ VAYRATHEN

เกมยังเป็นไฟล์เว็บล้วน ไม่มีขั้น build · ชุดทดสอบนี้ใช้แค่ Node.js (22 ขึ้นไป) กับ Playwright (เปิด Chromium แบบไม่มีหน้าจอ)

## ติดตั้งครั้งแรก

```bash
npm install                 # ติดตั้ง Playwright
npx playwright install chromium
```

## คำสั่ง

| คำสั่ง | ทำอะไร | เวลาโดยประมาณ |
| --- | --- | --- |
| `npm test` | รันทุกชุด (26 ข้อ) | ~6–8 นาที |
| `npm run test:data` | ตรวจข้อมูลเกมอย่างเดียว ไม่เปิดเบราว์เซอร์ | < 1 วินาที |
| `npm run test:smoke` | เล่นแบบผู้เล่นใหม่: สร้างบัญชี สร้างตัวละคร เดิน ตี เปิดหน้าต่าง เซฟ โหลดใหม่ · จอมือถือ | ~1 นาที |
| `npm run test:stress` | ทุกแผนที่ · ทุกอาชีพใช้ทุกสกิล · ทุกหน้าต่างทั้งไทย/อังกฤษ · Auto ล่ามอน · ตายแล้วฟื้นในเมือง | ~3–4 นาที |
| `npm start` | เปิดเกมที่ http://127.0.0.1:8080 (เซิร์ฟเวอร์ไฟล์เล็ก ๆ ไม่ต้องติดตั้งอะไรเพิ่ม) | |

รันไฟล์เดียวหรือเทสต์เดียวได้: `node --test tests/stress.test.js` หรือ `node --test --test-name-pattern="every job" tests/stress.test.js`

ถ้ามี Chromium อยู่แล้วในเครื่อง ตั้ง `CHROMIUM_PATH=/path/to/chromium` แทนการ `playwright install` ได้

## กติกา

- เทสต์เบราว์เซอร์ **ล้มทันทีถ้ามี error ใด ๆ** (`pageerror` หรือ `console.error`) แม้เกมจะยังเล่นต่อได้ ระบบใน `js/sys/` ที่ error ใน `EV.emit` ก็ถูกจับด้วย
- เพิ่มระบบใหม่: ถ้ามีหน้าต่างใหม่ (`mkWin`) จะถูกเปิดในเทสต์ "every window" ให้เอง · ถ้ามีสกิลใหม่ จะถูกยิงในเทสต์ "every job" ให้เอง · ถ้ามีแผนที่ มอน ไอเทม เควสต์ใหม่ จะถูกตรวจใน `data.test.js` ให้เอง
- เทสต์ไม่แตะเซฟจริงของคุณ: แต่ละรอบเปิดเบราว์เซอร์ใหม่ที่ไม่มีข้อมูลเก่า
