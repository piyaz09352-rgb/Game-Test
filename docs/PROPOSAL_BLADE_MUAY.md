# ข้อเสนอปรับสายนักดาบ และ สายนักมวย (ร่าง — รอเจ้าของเกมเลือก)

## นักดาบ — แนวทาง: ฟันหนัก · แนวหน้า · ปกป้องทีม
ปัญหาเดิม: ท่าพุ่ง 3 ตัวท่าเดียวกัน (พุ่งทะยาน · ทวนช้างศึก · พุ่งโล่กระแทก) · บัฟป้องกัน 3 ตัว (ท่าตั้งรับ · โล่ทองคำ · ปราการพิทักษ์) ·
ดึงมอนหมู่ 2 ตัว (คำรามช้างศึก · ปักธงศึก) · ฟันพสุธากับดาบพิพากษาภาพเดียวกัน

| ขั้น | สกิล | ข้อเสนอ |
|---|---|---|
| นักดาบ | ฝีมือดาบ · จังหวะดาบ · ปลุกใจนักรบ · ฟันคลื่น · พุ่งทะยาน · ตบเท้าธรณี · ท้าดวล · ท่าตั้งรับ | คงเดิม (พุ่งทะยาน = ท่าพุ่งประจำสาย) |
| ขุนศึก | ทวนช้างศึก | เปลี่ยนเป็น **ฟันเสยฟ้า**: ฟันเสยเป้าลอยขึ้นฟ้า แล้วตกกระแทกพื้น มอนรอบ ๆ มึน (ไม่ใช่ท่าพุ่งซ้ำ) |
| ขุนศึก | โล่ทองคำ (สะท้อนดาเมจ) | เปลี่ยนเป็น **ตอบโต้**: 8 วิ ถ้ามอนตีเรา ฟันสวนกลับทันที 200% ATK (ไม่ใช่บัฟโล่ซ้ำท่าตั้งรับ) |
| ขุนศึก | วิถีขุนศึก · ฟันซ้ำ · ฟันพสุธา · พายุดาบ · คำรามช้างศึก · ใจผู้พิทักษ์ | คงเดิม |
| ขุนพลปราการ | พุ่งโล่กระแทก | เปลี่ยนเป็น **กำแพงโล่**: ตั้งโล่ข้างหน้า 5 วิ ผลักมอนที่เข้ามา และกันดาเมจให้เพื่อนที่อยู่ข้างหลัง |
| ขุนพลปราการ | ปักธงศึก | เปลี่ยน: ปักธงค้างไว้ 15 วิ **เพื่อนในวงธง ATK +20% และฟื้น HP** (ไม่ใช่ดึงมอนซ้ำคำราม) |
| ขุนพลปราการ | ดาบพิพากษา | เปลี่ยนภาพ: ดาบแสงขนาดยักษ์ปักลงจากฟ้าแล้วแสงแตกเป็นแนว (ไม่ใช่ภาพเดียวกับฟันพสุธา) |
| ขุนพลปราการ | ดาบไร้เทียมทาน · ทัพหน้าทลาย · ราชันย์สงคราม · ปราการพิทักษ์ · กายวชิระ | คงเดิม |

รวม: ลบ 0 · เปลี่ยน 5

## นักมวย — แนวทาง: คอมโบ · ท่าแม่ไม้ · ปิดฉาก
ปัญหาเดิม: บัฟ ATK 3 ตัว (ไหว้ครู · รำมวยไหว้ครู · ปี่กลองเร้าใจ) · ท่าพุ่ง 3 ตัว (เข่าลอย · พุ่งจับทุ่ม · พุ่งเข่าโหนคอ) ·
เตะหมุนรอบตัว 3 ตัว (เตะตัด · จระเข้ฟาดหาง · พายุแข้ง)

| ขั้น | สกิล | ข้อเสนอ |
|---|---|---|
| นักมวย | ทั้ง 8 สกิล | คงเดิม (ไหว้ครู = บัฟประจำสาย · เข่าลอย = ท่าพุ่ง · เตะตัด = เตะรอบตัว) |
| ปรมาจารย์มวย | รำมวยไหว้ครู | เปลี่ยนเป็น **จรดมวย**: 10 วิ หลบการโจมตีได้ 30% และทุกครั้งที่หลบ สวนหมัดทันที (ไม่ใช่บัฟ ATK ซ้ำไหว้ครู) |
| ปรมาจารย์มวย | จระเข้ฟาดหาง | เปลี่ยนเป็น **จระเข้ฟาดหาง (แนวตรง)**: เตะเหวี่ยงไปข้างหน้าเป็นแนวกว้าง ผลักมอนถอยไปไกล (ไม่ใช่เตะหมุนรอบตัวซ้ำ) |
| ปรมาจารย์มวย | พุ่งจับทุ่ม | เปลี่ยนเป็น **จับทุ่มข้ามหัว**: คว้าเป้าเหวี่ยงข้ามหัวไปตกข้างหลัง กระแทกมอนตรงจุดที่ตก (ไม่ต้องพุ่ง) |
| ปรมาจารย์มวย | พันหมัด · หนุมานถวายแหวน · มอญยันหลัก · แม่ไม้ไม่ขาดสาย · กายหินผา | คงเดิม |
| เจ้าสังเวียน | ปี่กลองเร้าใจ | เปลี่ยน: เสียงปี่กลอง **เพื่อนรอบตัวตีเร็วขึ้น และมอนรอบตัวช้าลง** (บัฟทีม + ดีบัฟมอน ไม่ซ้ำบัฟตัวเอง) |
| เจ้าสังเวียน | พุ่งเข่าโหนคอ | เปลี่ยนเป็น **โหนคอตีเข่ารัว**: จับคอเป้าไว้ ตีเข่า 5 ครั้งติด เป้าขยับไม่ได้ (ไม่พุ่ง) |
| เจ้าสังเวียน | คาดเชือก · ศอกพายุ · พายุแข้ง · ปิดฉากมวยไทย · นาคบิดหาง · ยอดมวยไม่มีวันล้ม | คงเดิม |

รวม: ลบ 0 · เปลี่ยน 5
