# ข้อเสนอปรับสายเจ้าเหมียว และ สายเจ้าตูบ (ร่าง — รอเจ้าของเกมเลือก)

## เจ้าเหมียว — แนวทาง: ว่องไว · ข่วนรัว · ซน · มีเสน่ห์
ปัญหาเดิม: ข่วนรัว → ข่วนคลั่ง → พันรอยข่วน ภาพเดียวกัน 3 ขั้น · อ้อน/เสน่ห์ 3 ตัว (เหมียวอ้อน · หน้ามุ้งมิ้ง · มนต์เสน่ห์ราชินี) ภาพหัวใจเดียวกัน ·
บัฟ 3 ตัวภาพรำไหว้ครู (ครางคู · สัญชาตญาณนักล่า · พรแมวมงคล) · กระโจน 2 ตัว (กระโจนตะครุบ · กระโจนจันทร์)

| ขั้น | สกิล | ข้อเสนอ |
|---|---|---|
| เจ้าเหมียว | ทั้ง 8 สกิล | คงเดิม (ข่วนรัว · กระโจนตะครุบ · เหมียวอ้อน · ครางคู = ท่าประจำของแต่ละแบบ) |
| แมวป่าจอมซน | ข่วนคลั่ง | เปลี่ยนเป็น **ข่วนเป็นกากบาท**: ข่วนไขว้ 2 ทาง ทิ้งรอยเล็บเรืองแสงไว้บนตัวมอน แผลฉีกเลือดไหลแรง (ไม่ใช่ข่วนรัวแรงขึ้นเฉย ๆ) |
| แมวป่าจอมซน | กระโจนจันทร์ | เปลี่ยนเป็น **กระโดดกำแพง**: กระโดดข้ามหัวมอนไปลงข้างหลัง ตีจากด้านหลังติดคริแน่นอน (ไม่ใช่กระโจนซ้ำ) |
| แมวป่าจอมซน | หน้ามุ้งมิ้ง | เปลี่ยนเป็น **ไหมพรมพันตัว**: โยนไหมพรมกลิ้งไปพันมอนในแนว ตรึง 2 วิ (ไม่ใช่เสน่ห์ซ้ำ) |
| แมวป่าจอมซน | กรงเล็บแมวป่า · แมวหมุนพายุ · อุ้งเท้าเงา · ย่างแมว · แมวกวักนำโชค | คงเดิม |
| ราชินีวิเชียรมาศ | สัญชาตญาณนักล่า | เปลี่ยนเป็น **ตาแมวยามค่ำ**: 10 วิ มองเห็นจุดอ่อน ทุกครั้งที่ตีโดนลดเกราะเป้า 5% สะสม (ไม่ใช่บัฟคริซ้ำ) |
| ราชินีวิเชียรมาศ | มนต์เสน่ห์ราชินี | เปลี่ยน: มอนรอบตัว**หันไปตีกันเอง** 4 วิ (บอสไม่โดน) แทนหลงเสน่ห์เฉย ๆ |
| ราชินีวิเชียรมาศ | กรงเล็บราชินี · พันรอยข่วน · กระโจนดาวตก · หางดาวหาง · พรแมวมงคล · ชีวิตที่เก้า | คงเดิม |

รวม: ลบ 0 · เปลี่ยน 5

## เจ้าตูบ — แนวทาง: ภักดี · เฝ้าเพื่อน · งับไม่ปล่อย
ปัญหาเดิม: หอน/เห่า 4 ตัวภาพวงเห่าเดียวกัน (เห่าขู่ · หอนเรียกฝูง · หอนรวมพล · หอนจันทร์เพ็ญ) · งับ 3 ตัว (งับ · งับกระดูก · เขี้ยวราชันย์) ·
บัฟป้องกัน 3 ตัว (ยืนเฝ้า · ขนเหล็ก · ยืนหยัดไม่ถอย) · เทวดาเฝ้าเจ้านาย ซ้ำชุบชีวิตของหมอยา

| ขั้น | สกิล | ข้อเสนอ |
|---|---|---|
| เจ้าตูบ | ทั้ง 8 สกิล | คงเดิม (เห่าขู่ · งับ · ยืนเฝ้า · หอนเรียกฝูง = ท่าประจำ) |
| อัศวินหมาเฝ้าวัง | งับกระดูก | เปลี่ยนเป็น **งับไม่ปล่อย**: งับค้างไว้ 3 วิ เป้าขยับไม่ได้ ดาเมจทุกครึ่งวิ (ไม่ใช่งับแรงขึ้นเฉย ๆ) |
| อัศวินหมาเฝ้าวัง | หอนรวมพล | เปลี่ยนเป็น **ฝูงหมาป่าวิญญาณ**: เรียกหมาป่าวิญญาณ 3 ตัววิ่งไล่กัดมอน 10 วิ (ไม่ใช่วงหอนซ้ำ) |
| อัศวินหมาเฝ้าวัง | ขนเหล็ก | เปลี่ยนเป็น **ขุดหลุมหลบ**: ขุดดินมุดหลบ 2 วิ ไม่โดนอะไรเลย แล้วโผล่ขึ้นมากระแทกมอนรอบ ๆ (ไม่ใช่บัฟป้องกันซ้ำ) |
| อัศวินหมาเฝ้าวัง | อุ้งเท้าผู้พิทักษ์ · ฝูงพุ่ง · หมุนเขี้ยว · คำสัตย์ภักดี · ดมกลิ่นจุดอ่อน | คงเดิม |
| อัศวินบางแก้ว | หอนจันทร์เพ็ญ | เปลี่ยน: **พระจันทร์เต็มดวงขึ้น** 15 วิ อยู่ใต้แสงจันทร์ ATK และความเร็ว +20% มอนในวงกลัว (ไม่ใช่วงหอนซ้ำ) |
| อัศวินบางแก้ว | เทวดาเฝ้าเจ้านาย | เปลี่ยนเป็น **ยืนบังให้นาย**: 6 วิ รับดาเมจแทนเพื่อนรอบตัวครึ่งหนึ่ง และตัวเองรับดาเมจ −40% (ไม่ซ้ำชุบชีวิตของหมอยา) |
| อัศวินบางแก้ว | สายเลือดบางแก้ว · ยืนหยัดไม่ถอย · เขี้ยวราชันย์ · พายุหมาป่า · กระแทกโล่ · จ่าฝูง | คงเดิม |

รวม: ลบ 0 · เปลี่ยน 5
