# มาตรฐานตัวละคร VAYRATHEN

เอกสารนี้กำหนดขนาด ทิศ ท่า และรูปแบบไฟล์ของตัวละครทุกตัว ใช้ได้ทั้งภาพวาดมือ (เช่น ชาวบ้าน) และสไปรต์ที่โค้ดวาด (`js/gfx/sprites.js`)

## 1. สเกลในโลกเกม

| หัวข้อ | ค่า |
| --- | --- |
| หน่วยโลก | 1 หน่วย = 1 พิกเซลสไปรต์มาตรฐาน · หน้าจอแสดง x2 |
| ความสูงตัวละคร | 44–46 หน่วย (หัวถึงเท้า) · สัดส่วน chibi ≈ 2.1 หัว |
| จุดยึด | กึ่งกลางเท้า ตรงกับตำแหน่ง `x, y` ของตัวละครในโลก |
| เงา | เกมวาดเงาเองสำหรับสไปรต์โค้ด · ภาพวาดมือใส่เงาในภาพได้ |

## 2. ทิศ (8 ทิศ)

ลำดับมาตรฐาน: `S, SW, W, NW, N, NE, E, SE` (index 0–7)

ควรวาดให้ครบ 8 ทิศ ถ้าขาดทิศไหน เกมจะกลับภาพซ้าย-ขวาจากทิศคู่ตรงข้ามให้ แต่ของที่ติดตัวข้างเดียว (ถุงย่าม ผ้าคาดเอว) จะย้ายไปอีกข้าง จึงควรใช้การกลับภาพเฉพาะทิศหลัง เช่น `NE` จาก `NW`

วิธีดูทิศ: ดูว่าหน้าหันไปทางไหน ไม่ใช่ดูลำตัว · หน้าหันซ้ายลง = `SW` · หันซ้าย = `W` · เห็นหลังและหน้าโผล่ซ้าย = `NW`

## 3. ไฟล์ภาพวาดมือ

```
assets/characters/<id>/
  <id>.json        คำอธิบายชีต (ต้องตรงกับ MANIFEST ใน js/gfx/art.js)
  walk.png         หนึ่งไฟล์ต่อหนึ่งท่า
  idle.png ...
  source/          ภาพต้นฉบับก่อนตัด (ไม่โหลดในเกม)
```

| กฎ | ค่า |
| --- | --- |
| ขนาดช่อง (cell) | 160 × 256 px |
| จุดยึดเท้า | (80, 244) ในแต่ละช่อง |
| แถว | ทิศตามรายการ `dirRows` ในไฟล์ json (ชาวบ้าน: `S, SW, W, NW, N, E, SE`) |
| คอลัมน์ | เฟรมของท่า เรียงซ้ายไปขวา |
| พื้นหลัง | โปร่งใส ห้ามมีขอบแดง/ขอบขาวจากการลบพื้น |
| ความสูงตัวในภาพ | ประมาณ 228 px (เกมย่อให้สูง 46 หน่วย) |

ภาพที่วาดมาเป็นตารางอื่น ให้เขียนสคริปต์ตัดแบบ `tools/slice_villager.py`

### ปรับสเกลอัตโนมัติ

ภาพจากตัวเจนแต่ละรูปมักได้ขนาดตัวไม่เท่ากัน สคริปต์ตัดภาพจึงปรับให้เท่ากันเองทุกครั้ง (`tools/sprite_metrics.py`)

- ท่าเดิน/ยืน: ทุกทิศปรับให้สูงเท่ากัน 228 px (ปลายผมถึงพื้นรองเท้า ไม่นับเงา)
- ท่าอื่น (โจมตี ฯลฯ): เทียบกับท่าเดินทิศเดียวกัน ใช้ค่าเฉลี่ยระหว่าง "ความสูง" กับ "ความกว้างหัว" เพราะท่าย่อตัวสูงน้อยกว่า และตัวเจนมักวาดหัวเล็ก-ตัวยาวไม่เท่ากันในแต่ละรอบ
- ต้องรัน `slice_villager.py` ก่อน เพราะไฟล์ `metrics.json` ที่ได้คือค่าอ้างอิงของท่าอื่น

## 6. สถานะภาพวาดมือ

ตอนนี้ยังไม่มีภาพวาดมือในเกม ตัวละครทุกตัวใช้สไปรต์ที่โค้ดวาด (`js/gfx/sprites.js`)

เมื่อจะใส่ภาพใหม่: วางภาพที่เจนมาใน `assets/characters/<id>/source/` ตั้งชื่อ `<id>_<ท่า>_<ทิศ>_raw.png` สร้าง `<id>.json` แล้วรัน `python3 tools/slice_strip.py` จากนั้นเพิ่ม `<script src="assets/characters/<id>/<id>.manifest.js">` ใน `index.html` สคริปต์รับพื้นสีเรียบ ดำ เทา หรือลายตาราง ตัดป้ายกำกับใต้ภาพ และสร้างจังหวะขาก้าวให้ถ้าภาพเดินข้างไม่มีท่าขาผ่านกัน
