# ข้อเสนอปรับสายนักย่อง และ สายพ่อค้า (ทำแล้วใน v203)

## นักย่อง — แนวทาง: ซุ่ม · พิษ · เร็ว · ปลิดชีพ
ปัญหาเดิม: ตีเป้าเดียวแรง ๆ + คริตอนพราง 4 ตัว (แทงหลัง · ลอบสังหาร · ประทับเงามรณะ · เงาพิฆาต) ·
ติดตัวเพิ่มดาเมจ 5 ตัว · ท่าพุ่ง 2 ตัวหน้าตาเดียวกัน

| ขั้น | สกิล | ข้อเสนอ |
|---|---|---|
| นักย่อง | มีดคู่ · จุดตาย · สัญชาตญาณโจร · แทงหลัง · พุ่งเงาจู่โจม · เฉือนเอ็น · ระเบิดผงมึน · หลบหลีก | คงเดิม (แทงหลังเป็นท่าตีหนักเป้าเดียวประจำสาย) |
| จอมโจรเงา | ลอบสังหาร | เปลี่ยนเป็น **ฟันทะลุเงา**: พุ่งทะลุทุกตัวในแนว 180 ไปโผล่อีกฝั่ง (ไม่ใช่ตีเป้าเดียวซ้ำแทงหลัง) |
| จอมโจรเงา | จู่โจมจากเงา (ติดตัว คริ + ATK) | **ลบ** (ซ้ำกับใจเสือ) |
| จอมโจรเงา | ใจเสือ · ระบำใบมีด · ปามีดเงา · ก้าวเงา · ปล้นสะดม · อาบพิษอาวุธ | คงเดิม |
| พยัคฆ์เงา | ประทับเงามรณะ | เปลี่ยน: **ประทับตรา** เป้ารับดาเมจ +30% 8 วิ ถ้าตายระหว่างนั้น **ระเบิดเงา** ใส่มอนรอบ ๆ |
| พยัคฆ์เงา | พยัคฆ์พุ่งเงา | เปลี่ยนเป็น **พยัคฆ์กระโจน**: กระโดดลงกลางกลุ่ม ตีรอบจุดที่ลง + มึน (ไม่ซ้ำพุ่งเงาจู่โจม) |
| พยัคฆ์เงา | กรงเล็บจันทรา · เขี้ยวพยัคฆ์ · พันคมพยัคฆ์ · กรงเล็บพยัคฆ์ · เงาพิฆาต · ร่างมายา | คงเดิม (เงาพิฆาต = ปลิดชีพเป้าเลือดน้อย) |

รวม: ลบ 1 · เปลี่ยน 3

## พ่อค้า — แนวทาง: ขวาน · ใช้เงินเป็นพลัง · บัฟทีม
ปัญหาเดิม: ทุ่มเหรียญ → ถล่มทอง → หัตถ์ไมดาส คือท่าเดียวแรงขึ้น 3 ขั้น · หมุนขวาน 3 ตัว ·
โปรยเหรียญ / ห่าเหรียญทอง / พายุเงินทอง ซ้ำกัน

| ขั้น | สกิล | ข้อเสนอ |
|---|---|---|
| พ่อค้า | ทั้ง 8 สกิล | คงเดิม (ต่อราคาเปลี่ยนเป็นสกิลช่วยสู้แล้วใน v199) |
| นายวาณิช | ถล่มทอง | เปลี่ยน: **ทุ่มถุงทอง** ใส่เป้า ระเบิดเหรียญรอบเป้า รัศมี 80 + มึน (ไม่ซ้ำทุ่มเหรียญที่ตีเป้าเดียว) |
| นายวาณิช | พายุขวาน | เปลี่ยนเป็น **ขวานบูมเมอแรง**: ขว้างขวานพุ่งไปในแนวแล้วหมุนกลับ โดน 2 รอบ (ไม่ซ้ำขวานพายุ) |
| นายวาณิช | ขวานใหญ่ · เข็นเกวียนทลาย · ทวงหนี้ · ลมการค้า · ตาทองประเมินค่า · กำแพงเงิน | คงเดิม |
| มหาเศรษฐี | หัตถ์ไมดาส | เปลี่ยน: แตะแล้วเป้า **กลายเป็นทอง** หยุดนิ่ง 3 วิ และรับดาเมจ +50% ระหว่างนั้น (บอสไม่หยุด แต่รับดาเมจเพิ่ม) |
| มหาเศรษฐี | ห่าเหรียญทอง | **ลบ** (ซ้ำโปรยเหรียญ และพายุเงินทอง) |
| มหาเศรษฐี | ขวานเศรษฐี · วงขวานทอง · พายุเงินทอง · ตลาดนัดใหญ่ · กายทองคำ · บารมีเศรษฐี | คงเดิม |

รวม: ลบ 1 · เปลี่ยน 3
