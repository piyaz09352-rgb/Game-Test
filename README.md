# VAYRATHEN — อาณาจักรวายรา

ต้นแบบเกม MMORPG สไตล์ไทย เขียนด้วย HTML5 Canvas + JavaScript ล้วน ไม่ใช้ game engine

## วิธีเปิด

ดับเบิลคลิก `index.html` แล้วเล่นในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

## ทดสอบ

```bash
npm install && npx playwright install chromium   # ครั้งแรกครั้งเดียว
npm test                                          # ทุกชุด · npm run test:data แค่ตรวจข้อมูล (เร็วมาก)
```

รายละเอียดอยู่ใน [`tests/README.md`](tests/README.md)

### ชุดทดสอบเร็ว (v127)
`npm run test:fast` — 12 ชุดหลัก (ข้อมูล หน้าแรก เงินเบี้ย สูตรต่อสู้ การ์ดไอเท็ม สวมอุปกรณ์มือถือ ปุ่มสกิล ปุ่มยา หน้าต่างไม่วาดซ้ำ ระบบที่ปิดไว้ ออโต้บัพ กรอบมอนสเตอร์) ใช้ราว 3–4 นาที · รันทุกครั้งหลังแก้ · `npm test` = ชุดเต็ม 70+ ชุด (กว่า 30 นาที) ก่อนปล่อยเวอร์ชัน

## ปุ่มลัด

| ปุ่ม | การทำงาน |
| --- | --- |
| คลิก | เดิน / โจมตี / คุย NPC |
| 1–6 | Skill ในช่องลัด (ใส่ช่องจากหน้าต่าง Skill) |
| 7–8 | ยา HP / SP ที่ดีที่สุดที่มีในกระเป๋า |
| Space / C | กลิ้งหลบ |
| R | ขี่/ลงกวางทอง |
| T | จับมอนสเตอร์ HP ≤ 30% เป็นสัตว์เลี้ยง |
| X | นั่งพับเพียบ |
| A S E Q L ? | หน้าต่าง สถานะ สกิล กระเป๋า อุปกรณ์ (ใส่/ถอด/สลับ Card) บันทึก คู่มือ |
| B | ปุ่ม Auto: ตอนปิดอยู่จะเปิดหน้าตั้งค่า Auto ก่อน (ชุดสกิล ลำดับ ตีปกติ Buff เกณฑ์ฟื้น SP สำรอง นั่งพักอัตโนมัติเมื่อ HP/SP ต่ำ) แล้วกด "เริ่ม Auto" · ตอนเปิดอยู่กดเพื่อหยุด |
